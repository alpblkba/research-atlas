### Storage conventions

Each research direction has a `papers/` folder for literature notes. The CDNC `seminar/papers/` folder intentionally duplicates the two seminar-relevant notes from its parent direction. Elsewhere, prefer links across directions rather than unnecessary copies. The top-level `assets/papers/` directory stores local source PDFs only. The 2026 FHEmem/HEAWS report is archived under `directions/accelerators/fhe-seminar/`; original exports and three distinct LaTeX versions remain preserved under its `source-archive/` subfolder.
