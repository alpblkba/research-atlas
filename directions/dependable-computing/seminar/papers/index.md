# Seminar papers

RowHammer Across Modern Memory Architectures: Attacks, Defenses, and AI Security

As of 4 November 2026, the core set contains five papers: four deep reads and one focused/short read (QPRAC). These are the planned reads. The individual notes carry the evidence collected so far.

| Core paper | Venue | Role |
|---|---|---|
| [When Mitigations Backfire](woo-2025-when-mitigations-backfire.md) | ISCA 2025 | the central case of a protection mechanism introducing a different security exposure |
| [QPRAC](woo-2025-qprac.md) | HPCA 2025 | establish PRAC, ABO, RFM and mitigation-queue concepts needed for WMB |
| [Chronus](canpolat-2025-chronus.md) | HPCA 2025 | connect RowHammer thresholds to PRAC security and scaling cost |
| [GPUHammer](lin-2025-gpuhammer.md) | USENIX Security 2025 | compare GPU GDDR6 organization, access behavior and refresh constraints with CPU DRAM |
| [PRowhammer](shukla-2026-prowhammer.md) | ISCA 2026 | expose the dependency of GPU execution on host DRAM and shared libraries |

The existing WMB and QPRAC seminar files remain deliberate copies with their original reading notes preserved; they do not synchronize automatically. The three new seminar entries link to the maintained direction notes for sources and evidence, avoiding additional independent bibliographies.

The [direction catalogue](../../papers/index.md) contains all 19 named papers: five core, 12 citation-only, and two optional (GPUBreach and JENGA). Supporting papers are not additional core selections.
