# FHE accelerator seminar, 2026

I prepared the FHEmem and HEAWS comparison for an earlier KIT seminar. It received no course credit. I keep the drafts here so I can trace an argument or figure back to the version that used it.

## Source and outputs

- Preserved report-source snapshot, bibliography, [original reference notes](REFERENCES.md), and figure notes.
- [Provenance and SHA-256 checksums](provenance.md) for the historical snapshots.
- Full imported Seminar.zip and extracted versions, including all three distinct LaTeX drafts and preview images.
- [Slides](../slides/README.md): available presentation files and their versions. The earlier 27-slide and 39-slide Markdown snapshots are missing; see the provenance record.
- [Assets](assets/README.md): supplementary material added later. Original LaTeX figure dependencies remain under figures/ to preserve relative paths.
