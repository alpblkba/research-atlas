# TensorFlow Lite Micro

[Source](https://proceedings.mlsys.org/paper_files/paper/2021/hash/6c44dc73014d66ba49b28d483a8f8b0d-Abstract.html) · [arXiv v3](https://arxiv.org/abs/2010.08678v3) · [Direction catalogue](index.md)

## Reading focus

Laxity can move a whole activation arena between SRAM banks. TensorFlow Lite Micro lets me look one level inside that decision: its interpreter uses a single tensor arena with a statically planned layout.

- Laxity's network is generated by ST Edge AI Core rather than TFLM, so this paper is the comparison point for how a runtime decides where activations live, the placement planner that Laxity does not have yet.

Reading tier: core for the Laxity thread.

## Source record

Source check by agent, 2026-11-06: abstract from arXiv v3; venue from the MLSys 2021 proceedings listing.

arXiv v3 abstract: embedded processors have far less compute, memory and energy than mobile devices, so models and runtime must fit in kilobytes; TF Micro uses an interpreter-based design to handle these limits and hardware diversity, with a reported small footprint and low runtime overhead.
